# 이브리프 쇼츠: 경기도교육감 개표상황표 위조 의혹 여야 공방 (2026-11-10)

원본 영상: YTN 「국민의힘 "조직적 개표 부정" 공세...민주당도 "철저한 수사" 당부」 (https://youtu.be/HKEEY5IuDvs)

## 쇼츠 화면 제목
- 1줄(흰색): 개표상황표 위조 의혹
- 2줄(빨강): 여야 "철저 수사"

## 장표
1. 표지: 개표상황표 위조 의혹 / 국힘 "조직적 부정" / 민주도 **"철저 수사"**
2. 타임라인: 6월 3일 개표 결과 잘못 입력 → 6월 11일 선관위 사과·정정 → 11월 10일 특검 압수수색(**조직적 은폐** 여부 수사)
3. 발언 모음: 박충권 국민의힘 수석대변인 / 안태훈 민주당 상근부대변인(**중대한 범죄**)
4. 사진+전망: 재외국민 전자투표 법안까지 겨냥, **압박 수위** 높일 전망 + 하단바

## 사실 검증 메모
- 영상의 '전자투표 도입 법안'은 경인일보 보도상 '재외국민 온라인 전자투표' 법안이라 장표·나레이션에 '재외국민'을 명시.
- 한국일보: 선관위가 6월에 이미 수치를 정정해 이번 특검 수사는 개표 결과·당선인 결정과 무관 → 2장에 한 줄 넣음.
- 은닉·위조·조직적 은폐는 특검 수사 중인 혐의(확정 아님). '조직적 개표 부정'은 국민의힘 주장으로 귀속.
